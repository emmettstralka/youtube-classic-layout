# YouTube Classic Layout

Chrome extension that restores the classic YouTube watch-page layout when YouTube’s redesign experiment is active.

| Redesign experiment | Classic (this extension) |
|--|--|
| Comments in a right-hand panel | Comments under the video |
| Related videos under the player | Related videos in the right sidebar |
| Theater often disabled or not full-bleed | Full-bleed theater mode |

## Install

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. **Load unpacked** and select this folder (the one with `manifest.json`)
4. Open a YouTube video and hard refresh (`Cmd+Shift+R` / `Ctrl+Shift+R`)

To update after pulling changes: click **Reload** on the extension card, then hard refresh YouTube.
